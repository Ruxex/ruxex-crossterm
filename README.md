# ruxex-crossterm

This repository is a Ruxex-maintained downstream fork of [crossterm](https://github.com/crossterm-rs/crossterm).
It exists solely to publish the Ruxex-compatible package to crates.io and support the Ruxex dependency graph.
Changes are intentionally limited to the compatibility work required by Ruxex.

Thanks to the crossterm maintainers and contributors, and to OpenAI OSS Forks for the prior work carried here.
